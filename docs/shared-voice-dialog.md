# Голосовой диалог с хранением в YDB

Поставки общего режима выполняются через GitHub Actions по [инструкции](deployment.md).
Общий режим вызывает `AliceChess` и существующие обработчики через `shared_chess/dialog.py`.
Сохраняются приветствие, вопрос о цвете, первый ход за чёрных, подтверждения новой игры,
сдачи и ничьей, выбор сложности, помощь, продолжение партии, отмена и точный повтор.

Запись игрока хранит `dialog` с полным совместимым снимком состояния и `dialog_revision`.
Снимок привязан к ID и ревизии партии через `dialog_game_id` и `dialog_game_revision`.
Эта привязка проверяется при чтении и резервировании, включая ходы от прежней версии API.
Этап выбора цвета сохраняется уже до создания партии. После подтверждения новой игры
экран получает состояние без активной партии до выбора цвета. Готовая партия получает
новый ID и следующую генерацию. Голосовые ходы дополняют проверяемую историю общей партии.

Голосовая команда проходит резервирование, выполнение штатного обработчика вне транзакции
и атомарное сохранение позиции, диалога и реплики. Касание очищает снимок диалога и обновляет
его ревизию. `game_ref.dialog_revision` связывает следующее «да» с показанным вопросом.
При изменении позиции или вопроса другой сессией требуется обновить состояние.
Повторная доставка возвращает сохранённую реплику. Ошибка движка при выборе чёрных
сохраняет вопрос о цвете. Контекст с подтверждением прежней версии пилота также поддерживается.

Семь сравнительных сценариев в `tests/test_voice_dialog_parity.py` проверяют весь `response`,
включая TTS и кнопки, позицию, этап диалога, цвет, сложность и число вызовов движка.
Исходные эталоны старта за чёрных, продолжения с отменой и повтора сохранены в
`tests/fixtures/voice_dialog/`. Все семь сценариев прошли с настоящей тестовой YDB
и фиксированным ответом движка. Также прошли две существующие интеграционные проверки YDB.
Локальные проверки в `tests/test_shared_chess.py` покрывают утрату контекста, устаревшее «да»,
ошибку Stockfish, совместную историю голоса и экрана и исключение внутренней команды
`voice` из публичного device API. Пакет API включает штатные обработчики для авторизованного `/v1/skill`.

Итоговый локальный прогон на Python 3.13.18 дал **136 passed, 2 skipped, 16 subtests passed**.
Отдельный прогон с тестовой YDB дал **9 passed**. Ruff и проверка форматирования прошли.
Все три пакета функций собраны и проверены на компиляцию и изолированный импорт модулей.
Настоящий локальный Stockfish сделал первый ход за чёрных; повтор вернул тот же ответ.
Предыдущий пакет API прочитал созданную голосом партию и применил ход, после чего
новый голосовой обработчик восстановил актуальную позицию с полной историей.
